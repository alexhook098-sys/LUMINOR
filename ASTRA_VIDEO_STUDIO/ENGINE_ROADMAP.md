# Engine integration roadmap

## Rendering
Единый RenderJob должен принимать URI изображений, порядок кадров, длительность, FPS, размер, аудио и параметры кодека.
- Первый backend: Android MediaCodec + MediaMuxer либо проверенная FFmpeg-сборка.
- UI не зависит от конкретного backend: использовать интерфейс RenderEngine.
- Экспорт — в foreground service с уведомлением, отменой и восстановлением состояния.

## RIFE
- Отдельный JNI/NDK-модуль; runtime и модель должны соответствовать ABI/GPU.
- Проверить NCNN Vulkan и реальную поддержку Mali на Exynos 850.
- Начать с короткой последовательности и низкого разрешения.
- CPU fallback, небольшие batch, освобождение native buffers.
- Не обещать коэффициент ускорения до измерений.

## Optical Flow
Это отдельная оценка движения, не синоним RIFE. Проверить лицензируемую реализацию (например, OpenCV DIS/Farneback), артефакты на окклюзиях и быстрых движениях.

## Device safeguards
- Проверка свободной памяти и температуры.
- Пакетная обработка, контроль нативной памяти.
- Сохранение промежуточных кадров и восстановление после сбоя.
- Профили Preview / Balanced / Quality.
