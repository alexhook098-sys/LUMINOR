## Release checklist
- [ ] Зафиксировать точные версии и commit SHA.
- [ ] Проверить все транзитивные зависимости и встроенные бинарники.
- [ ] Проверить лицензию каждого model weight и dataset.
- [ ] Проверить кодеки, патентные условия и целевые рынки.
- [ ] Добавить требуемые LICENSE/NOTICE и исходный код, если требуется.
- [ ] Сформировать SBOM для релизной сборки.
- [ ] Разрешить релиз только при статусе approved для всех встроенных компонентов.
